# Análise de Finanças Pessoais (Excel)

## Introdução

Esse projeto consiste em um dashboard desenvolvido em Excel para monitoramento financeiro pessoal, com foco em análise de entradas, gastos e comportomanto de consumo ao longo do tempo.

O objetivo é transformar dados de gastos do dia-a-dia em informações claras, como identificações de gastos extremos e aumentos de gastos sazonais, para a melhorar do controle financeiro individual.

Base de dados baseada em: https://www.kaggle.com/datasets/entrepreneurlife/personal-finance

## Objetivo

- Acompanhar receitas e despesas mensais
- Avaliar os gastos ao longo do tempo
- Identificar padrões de consumo
- Melhorar controle financeiro através da análise gráfica

## Ferramentas Utilizadas

- Microsoft Excel (Principal)
- Tabelas dinâmicas
- Segmentação de dados (slicers)
- Fórmulas para cálculo de estatísticas chave

## Dashboard

O dashboard consiste de:

### Visão Geral Financeira

- Comparação entre entradas e saídas
- Calculo do saldo mensal
- Percentual da renda comprometida

### 5 Maiores Gastos Mensais

- Gráfico com as 5 categorias com maior impacto na renda mensal para análise de concentração de despesas.

### Tipos de Pagamento

- Gráfico comparando os diferentes tipos de pagamento (cartão prata, cartão platina, débito em conta) para compreensão de comportamento financeiro.

### Evolução Temporal

- Série temporal com os gastos de todos os meses analisados para identificação de tendências e variação ao longo do tempo

### Análise Interativa

O dashboard contém um slicer interativo com filtro mensal, o que permite análises dinâmicas por período específico, o que permite:

- Comparar diferentes meses
- Identificar mudanças no padrão de consumo
- Avaliar variações no saldo ao longo do tempo
